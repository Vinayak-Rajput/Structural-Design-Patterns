Dynamic Coffee Shop Billing

A coffee shop app sells base beverages (Espresso, DarkRoast).
Customers can dynamically stack add-ons like Milk, Oat Milk,
Espresso Shots, and Whipped Cream. Creating separate subclasses
for every combination (DarkRoastWithMilkAndWhip) creates a class explosion.

Task: Design a base Beverage interface and wrap-around decorators for each
ingredient so costs and descriptions accumulate dynamically at runtime (e.g.,
new Whip(new OatMilk(new DarkRoast()))).
